# Data Collection and Processing Using JSON, APIs and Web Scraping

**Course:** Python for Data Engineering  
**Purpose:** Educational ETL pipeline for API extraction, website scraping, JSON validation, processing and analysis.

## Sources
- API: https://jsonplaceholder.typicode.com/users
- Educational scraping site: https://books.toscrape.com/

## Project files
- `api_data.py`: fetch, validate and save API users.
- `web_scraping.py`: parse, validate, deduplicate and save at least 20 books, following pagination when necessary.
- `storage.py`: shared JSON storage, atomic writes and record validation.
- `json_processing.py`: load both datasets, filter records and generate the combined report.
- `analysis.py`: company frequencies, price statistics and rating distributions.
- `main.py`: command-line orchestration with failure reporting.
- `tests/test_pipeline.py`: isolated tests using mocked network responses.
- `data/users.json`, `data/books.json`, `data/report.json`: **generated by running the pipeline**; never fabricated.

## Setup (Windows PowerShell)
From this project directory:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, use `.venv\Scripts\python.exe` instead of `python` in the following commands.

## Execute

```powershell
python main.py --step all --books 20
```

Individual stages (run API and scraping before report/analysis):

```powershell
python main.py --step api
python main.py --step scrape --books 20
python main.py --step report
python main.py --step analyze
```

You can also run `python api_data.py`, `python web_scraping.py`, `python json_processing.py` and `python analysis.py` separately.

## Test

```powershell
python -m unittest discover -s tests -v
```

Tests run without an internet connection using mocked HTTP responses. Live data collection requires network access. The program fails rather than overwriting existing data with empty results if collection fails.

## Data schemas
`users.json` contains an array of objects with `name`, `username`, `email` and `company` (all nonempty strings). `books.json` contains an array of objects with `title` (string), `price` (nonnegative numeric GBP value) and `rating` (integer 1–5). `report.json` includes totals, average price, users in companies containing “Group”, books rated above four stars, company frequencies and descriptive book statistics.

## Cleaning and reliability
Text fields are stripped; prices are parsed into numbers; ratings are mapped to integers; malformed records are skipped with warnings; duplicate scraped books are ignored. Requests have timeouts and HTTP errors are checked. Missing/invalid input files cause explicit failures. JSON output is written atomically to avoid leaving partially written files.

3. Run the unit tests and save a screenshot or text copy of the test output.
4. Capture the command and successful pipeline output for execution evidence.
5. ZIP the **entire** project, including the three generated JSON files, source code, README, requirements and tests. Do not submit empty placeholder datasets.

## Limitations
This is a small educational pipeline, not a production scheduler. Scraping depends on the source website's current HTML structure. Network errors are reported and terminate the relevant run; no fabricated fallback data is used. This project does not claim that live extraction succeeded until it has actually been run.
